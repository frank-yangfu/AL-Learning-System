# AL 学习机 · AL-Learning-System

> 一台跑在家里的 AI 学习机：开机即是宫格桌面，AI 学伴主动开口陪学。
> **零第三方依赖**，Python 标准库即可运行；不配任何 API Key 也能讲知识、出题、判分。

## 核心理念

- **苏格拉底式引导**：导师不直接给答案，而是用提问引导你独立思考。
- **角色 / 情绪驱动**：每个学习角色有独立人格与教学风格；系统检测你的学习情绪
  （好奇 / 困惑 / 挫败 / 兴奋 / 满足 / 无聊 / 焦虑 / 平和），据此调整教学策略。
- **学习连续性**：会话、检查点（checkpoint）、关系阶段递进。
- **知识图谱**：对话中自动抽取知识点与关系，用力学布局可视化。
- **内置 K12 课程（适配青海西宁）**：预置小学 → 高中主干学科的核心知识点（共 90 个），
  课程依据国家义务教育/高中课程方案设置，教材版本与**西宁地区中小学现行使用的 人教版/统编版**一致，
  学生可在「课程目录」中自主选择想学的课程，导师会针对该知识点用苏格拉底式提问引导学习。
- **课后测试与掌握度追踪**：每学完一个知识点，可一键发起「📝 课后测试」——导师用提问逐步检验你是否
  **真正理解并能独立运用**该知识点（而非直接给答案），采用「闯关式」三关测评（说出来·做出来·讲明白），结束后给出
  「掌握 / 熟悉 / 了解 / 未掌握」五级判定并记入掌握度，
  引导学生自主完成测试、查漏补缺。
- **语音 + 文字双输入**：对话支持文字与 🎤 语音输入；开启「🎙️ 语音模式」后导师回复自动朗读，
  尤其适合**英语口语**练习——选英语课程会自动切换到英语外教「Emma 老师」并开启语音对话。

## 使用步骤

1. **注册 / 登录**：首次使用点「注册」创建一个本地账号（数据仅存于本机 `data/app.db`）。
2. **设置模型**：进入「设置」页，填入 DeepSeek API Key（Base URL 默认
   `https://api.deepseek.com/v1`，模型 `deepseek-chat`）。默认填了 Key 即自动使用真实模型；没填 Key 会自动降级到「演示模式」。想强制用演示模式（免密钥）时，可手动勾选「演示模式」开关。
3. **浏览课程（推荐）**：进入「学习」页，点「📚 浏览课程目录」，按
   **学段 → 学科 → 年级 → 知识点** 选择你想学的内容。系统已内置一位通用导师
   「小艾老师」（标注「系统内置」），无需自建角色即可开始学习。
4. **（可选）创建专属角色**：想自定义导师人格/风格时，到「角色」页创建；
   系统内置角色不可编辑或删除。
5. **开始学习**：选好角色与课程后，开始苏格拉底式对话；导师会针对所选知识点引导。
6. **语音学习（尤其英语）**：对话框旁有 🎤 麦克风（点一下开始/停止语音输入）、🔊 朗读、
   🎙️ 语音模式（导师回复自动朗读）。**学英语时**，在课程目录选任意英语知识点，系统会自动切换到
   英语外教「Emma 老师」并开启语音模式——你用语音说英语，导师用英语提问并自动朗读、纠正发音与语法，
   形成沉浸式口语对话。
7. **课后测试（掌握度测评）**：在「学习」页先选好一个知识点，再点对话框旁的「📝 课后测试」
   （需先选课程）。导师会进入测评模式，逐个核心要点提问，要求你用自己的话解释或举例；答错也不批评，
   只给提示引导你想通。采用闯关式测评：第一关「说出来」(理解) → 第二关「做出来」(应用) → 第三关「讲明白」(迁移)，
   三关全过即「掌握」，并记入该知识点的掌握度（了解 / 熟悉 / 掌握）
   （在「当前课程」旁以彩色徽章显示）。可反复测试巩固。
8. **查看知识图谱**：在「知识图谱」页查看自动构建的概念网络。

## 🏠 学习机模式（2026-11-11 改版，对标科大讯飞 AI 学习机）

原来的 AL 是「网页式」的自学系统，入口分散、孩子要自己找菜单。本次改版把首页做成**学习机桌面**：
开机即是**大图标宫格 + AI 学伴主动开口**，孩子不用找，AI 自己把今天该做什么串起来。

### 新增形态

| 模块 | 说明 |
|---|---|
| **顶部状态条** | 孩子头像/名字 + 🔥连续天数 + ⭐星星 + ⏱今日时长/目标 |
| **AI 学伴卡**（首页 C 位） | 小艾按**真实学情**主动开口：有断点先接着学、有错题先复习、有薄弱点先练、到目标了给表扬 |
| **学习机宫格**（4×2） | 同步学 / 精准学 / AI解题 / 错题本 / 学情报告 / 课外阅读 / 我的成就 / 家长中心 |
| **常驻 AI 学伴球** | 右下角悬浮球，应用内任意页面一键唤起 |
| **全屏 AI 学伴** | 小艾先开口 → 快捷指令（今天学什么/讲讲这道题/练几道题…）→ 语音输入 + 语音朗读 → 建议动作按钮 |
| **底部导航** | 首页 / 同步学 / 练习 / 学伴 / 我的 |

### 学伴不是摆设：它知道这些真实数据

`GET /api/ai/companion/opening` 汇总学情后按优先级生成开场白与动作：
断点续学快照 → 错题待复习数 → 薄弱知识点（level≤1）→ 今日目标进度 → 首次引导。

`POST /api/ai/companion/chat` 走学伴人格 Prompt（温暖、短句、不训斥、不给最终答案），
并把「孩子：X / 今天已学 / 连续天数 / 错题数 / 上次学到哪 / 正在看的课」作为上下文喂给模型。

> 演示模式（无 API Key）下学伴由本地规则引擎 `companion.mock_companion` 回复，情绪识别（累/烦/不会）
> 会主动降难度 + 提议休息，保证零密钥也能完整体验。

### 离线（APK）也能用

`static/offline-shim.js` 新增两个接口的**本地规则实现**：断网时学伴卡照样有开场白和动作按钮，
不会出现 503 空白卡。

### 相关文件

- `companion.py` —— 学伴人格 Prompt / 开场白规则 / 演示模式回复（纯逻辑，可单测）
- `static/index.html` —— `#view-home` 重排 + `#view-companion` + `#companion-fab` + 底部导航

## 💾 学习进度持久化（2026-11-11 修复）

**问题**：学习进度原来只存在浏览器 `localStorage` 里 —— 换设备、清缓存、换浏览器、切孩子都会「进度归零」，
账号和服务端数据对不上。

**现在的机制**：

| 数据 | 存储位置 | 跨设备恢复 |
|---|---|---|
| 知识点已学 / 已掌握 | 服务端 `study_records` 表（本地 localStorage 只做缓存） | ✅ |
| 课外阅读进度 | 同上，key 前缀 `story:<id>` | ✅ |
| 断点续学（学到第几章） | 服务端 `study_progress` + 本地缓存 | ✅ |
| 星星 / 勋章 | 服务端 `stars` / `achievements` | ✅ |
| 掌握度 / 错题本 | 服务端 `mastery` / `mistakes` | ✅ |

写进度时**本地立即生效 + 400ms 防抖上云**；登录后从服务端**合并回本地**（取状态高者），
离线期间学的增量会在联网后自动补传。

**账号绑定**：每个孩子对应一个独立账号 `child_<名字>`，切换孩子时本地数据会打包进
`al_scope_<账号名>` 并各自还原，不会串号。

### 相关接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/study/records` | 拉取本账号全部知识点/读物进度 |
| POST | `/api/study/records` | 上传增量（只增不减，status 取大） |

### 验收脚本

```bash
node tools/_persist_verify.js     # 清空本地后能否找回进度
node tools/_persist_multikid.js   # 多孩子之间是否隔离
node tools/_persist_relogin.js    # 浏览器重启后自动登录到同一账号
node tools/_persist_ratelimit.js  # 连续刷新是否被鉴权限流打挂
```

## 🧠 学伴的 AI 能力（三档，不用非配大模型不可）

| 档位 | 前提 | 能力 | 离线 |
|---|---|---|---|
| **① 内置知识引擎**（默认） | 无，勾选「演示模式」即可 | 讲 637 个知识点的讲义、从 1485 道题库出题、判分给解析、情绪安抚 | ✅ 完全离线 |
| **② 云端大模型** | 填 DeepSeek / OpenAI 兼容 Key | 上面全部 + 自由问答、讲任意题、闲聊 | ❌ 需联网 |
| **③ 家用模型服务器** | 运行服务器的电脑装 Ollama | 同②，且零成本 | ✅（电脑需开着） |

**关键**：模型配置保存在**服务端**（跟着账号走），平板/手机打开即生效，**平板本身不需要装任何模型**。

① 的实现：`companion.py` 里的「本地知识引擎」——`bind_knowledge()` 注入 `curriculum.get_lesson` 与 `TOPIC_INDEX`，
提供 `explain_topic()`（讲讲义，按【一句话懂】【为什么重要】【具体怎么做】拆段）、`quiz_present()` / `quiz_grade()`
（出题 + 判分 + 解析）、`search_topics()`（按关键词找课）。前端把它渲染成**可点击卡片**（选项直接点、答完出判分卡）。
APK 离线包在 `offline-shim.js` 里有同一套逻辑的 JS 版。

详见 `使用说明_平板部署与AI配置.md`。

## API 速览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/register` `/api/login` | 注册 / 登录，返回 token |
| GET/POST | `/api/settings` | 读取 / 保存 LLM 配置 |
| GET/POST | `/api/roles` | 角色列表 / 创建 |
| PUT/DELETE | `/api/roles/<id>` | 编辑 / 删除角色 |

| GET | `/api/sessions/<id>` | 会话消息 |
| POST/DELETE | `/api/sessions/<id>/checkpoint` | 标记 / 清除检查点 |
| GET | `/api/knowledge_graph?role_id=` | 知识图谱节点与边 |

## 与原始文档的关系

本原型实现了文档中描述的核心玩法（苏格拉底双层 Prompt、情绪驱动教学策略、
角色/课程、知识图谱、学习连续性），并用最简技术栈落地，方便本地自学与二次开发。
