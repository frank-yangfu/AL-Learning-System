一、先修的 3 个致命 bug

问题根因修复与影响
① 注册 / 登录直接 500`_client_ip` 被写成**模块级函数**，却按 `self._client_ip()` 方法调用 → AttributeError。移入 Handler 类，改为方法。任何账号都登不进来，属于一级阻塞。
② 前端改动「改了等于没改」`static/sw.js` 是 cache-first + 固定版本号 `al-v1`，浏览器永远返回旧 `app.js`。改 network-first + `al-v3` + skipWaiting + clients.claim（断网仍回退缓存，离线可用不变）。
③ 网页版半数接口是死的`static/offline-shim.js` 用 `window.AL_OFFLINE !== false` 判定 → 网页里恒为 true，把所有接口（对话/错题/精准学/进度…）替换成「离线占位」。改为**显式开启**：只有 APK（`AL_OFFLINE === true`）或 `file://` 才拦截；http 网页版完全不拦截。APK 离线行为不变。

六、怎么用

错题本（精准学 → 📕 错题本）
① 顶部看掌握率和待复习数量；

② 下次打开首页顶部出现「⏯ 继续学习」，写着学的是哪一课、多久之前；

④ 换设备、换浏览器也能续（服务端存的那份）。

七、两点注意

1. 如果你之前把系统装成了「添加到主屏幕」的 App：旧的离线缓存会拿老代码。第一次打开若发现界面没变化， 在浏览器里 Ctrl + F5 强刷一次 即可（Service Worker 已改成网络优先，之后会自动更新）。

2. 如果要重新打包 APK 离线包：本次改了 static/offline-shim.js 与 static/app.js， 按老规矩 同步 static → prep_apk.py → gradlew 重打一次。APK 的纯离线行为保持不变 （只有包内 AL_OFFLINE=true 时才拦截接口）。
