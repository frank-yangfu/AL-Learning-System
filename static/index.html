🔊 语音朗读设置（平板上可调音色，告别机械嗓音）

网页端「电脑语音服务器 / 云端」= 由本机服务端用 edge-tts 生成音频，最稳、音质最好。装成 APK 后，若在下面填了电脑地址，就通过网络从电脑取音频（华为等没有语音引擎的手机靠这条出声）；没填则用手机系统自带引擎，完全离线。
当前：未配置
华为等手机出厂不带「文字转语音」引擎、也无法下载语音包，系统朗读这条路走不通。改用电脑出声：
① 在电脑上双击 启动_AL系统_语音版.bat（黑窗口里会显示「★ 手机/平板请填这个地址」，形如 192.168.1.5:8000）；
② 手机连同一个 WiFi，把那个地址填进上面的框，点「💾 保存」；
③ 点「🔌 测试语音服务器」——出现 ✅ 就说明通了，点「🔊 朗读测试」即可听到声音。
电脑关机或不同 WiFi 时会没声音，此时程序会自动改用手机自带引擎（如果有）。
带 ★ 的是本机高质量嗓音。若列表里没有好听的：iPad 可在「设置 → 辅助功能 → 语音内容 → 嗓音」下载「Yue / Ting-Ting」等 Siri 嗓音；Android 可在「设置 → 语言和声输入 → 文字转语音输出」里安装 Google 普通话（Enhanced）。下载后点「刷新可用嗓音」即可选用。
装成 App 的手机/平板若没有声音：先点「🩺 语音自检」看第一行写的当前朗读方式——
· 显示「电脑语音服务器」→ 点「🔌 测试语音服务器」确认电脑开机、同一 WiFi；
· 显示「无可用引擎」→ 华为等机型请按上面「电脑语音服务器地址」三步走；不要去系统设置里找「文字转语音」，部分机型根本没有这一项。
· 显示「手机系统语音引擎」但没声音 → 检查媒体音量是否被调成 0、是否插着耳机/连着蓝牙。
机械感主要来自系统默认嗓音。先在本机设置里下载「高质量 / Enhanced / Neural」嗓音并手动选中，效果最明显；风格预设会自动调整语速与音调，可再用滑块微调。

👨‍👩‍👧 家长小贴士

防止孩子退出学习应用去玩游戏：安卓平板自带「屏幕固定」功能，开启后平板只能停留在本应用，退出需要家长密码。
开启方法（安卓 9 以上通用）：
① 打开平板「设置」→「安全和隐私」（或「生物识别和安全性」）→「更多安全设置」；
② 找到「屏幕固定」（部分机型叫「应用固定」），打开开关，并开启「固定前要求解锁」；
③ 按「最近任务」键（□ 或横条），找到本应用的卡片，点卡片下方的图钉图标 📌；
④ 固定后孩子只能使用本应用。家长取消：同时按住「返回 + 最近任务」键（或按指纹/输入锁屏密码）。
华为/荣耀：设置 → 安全 → 更多安全设置 → 屏幕固定。
小米/红米：设置 → 特色功能 → 手机分身/应用锁 附近可找到「屏幕固定」；或在最近任务里长按卡片 → 点击 📌。
三星：设置 → 生物识别和安全性 → 其他安全设置 → 固定窗口。
💡 建议：每天固定时段（如放学后 30–60 分钟）使用本应用，配合系统「屏幕使用时间」限额，效果更好。
